How to read this

Every run uses the existing rival-gate setup and a Cinder RWD, with the player parked. Traffic-free and traffic runs use the same route and line; the clear run is not the separate Uptown / Clear driving mode. These are AI-alone observations, not player race results.

Segment time includes time spent recovering or stationary. Entries count visits, not successful traversals. Time differences can move between neighbouring bins and are not proof of a local cause. Slowdown “loss” is the existing census estimate relative to the rival’s own plan, including recovery; it is not measured time saved by removing traffic. Corner-plan limitations can therefore exist without a slowdown marker. Approximate traffic contact uses the gate’s box-overlap heuristic, not collision impulses. Unvisited bins stay grey; a timeout is a DNF, never a successful traversal.
