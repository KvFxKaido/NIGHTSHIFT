## MCLA methodology and caveats

*Sheet: MCLA Sources, A41:B50.*

|  |  |
|---|---|
| Version | v0.2 adds MCLA. Original six MC3 tabs remain a preserved v0.1 snapshot, including their original scope wording. |
| Confidence | A = official/game data; B = independent community agreement; C = one structured source; D = unresolved conflict or unverified field. |
| Money | All vehicle and tuning figures are in-game dollars, not real-world prices. Quotes do not establish total lifetime spending through successive upgrades. |
| Missing values | Blank means not verified or not applicable, never zero. Price-plus-tune excludes DUB variants, police variants and disputed 1098R tuning. |
| Roster grain | One showroom vehicle/variant per ID; four DUB variants and five police variants are separate. Ballerz stays a reward preset, not a second roster row. |
| Reward coverage | Named scripted vehicle awards only; excludes starter selection, repeatable generic wagers and cash in place of full-garage prizes. No chronology inferred from row order. |
| Stats | Official sample has graphical stat bars, not numeric values. No invented digitization or cross-game raw-rating comparisons. Two official speed observations retained with conditions caveat. |
| Availability | Edition labels describe content inclusion, not current storefront availability. No assertion about current multiplayer service status. |
| REP gates | Group gates are normal purchase thresholds. Story hooks, content ownership, DUB wins and legacy unlock flags remain additional requirements. |
| Verification scope | Sources checked 2026-09-12. Search-index access is labeled separately from full-page access. No emulator or console validation performed. |
